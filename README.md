# НМЦД / Лаборатория цен

Прототип по кейсу «Обоснование начальной максимальной цены договора» хакатона «ИИ в системе управления МФТИ». Он собирает открытые предложения, показывает, какие характеристики удалось сверить, рассчитывает цену и формирует проверяемый отчёт.

[Открыть рабочее демо](https://hpfs.ru/hack-phystech/)

## Запуск

Требуются Node.js 22+ и npm. Интернет нужен для живого поиска. Два демонстрационных примера работают без подключения к каталогам.

```sh
npm ci
npm test
npm start
```

Откройте http://127.0.0.1:8780/hack-phystech/. Остановка — Ctrl+C. Переменные `HOST` и `PORT` задают интерфейс и порт, значения по умолчанию `127.0.0.1` и `8780`.

```sh
docker build -t phystech-price-lab .
docker run --rm --name phystech-price-lab -p 127.0.0.1:8780:8780 phystech-price-lab
docker stop phystech-price-lab
```

## ИИ-поиск в интернете

Веб-поиск запрашивает до десяти карточек от разных продавцов за один запрос. На сервере может использоваться Timeweb; без его настройки используется Exa. Для известных магазинов сервер проверяет опубликованную цену, валюту и наличие непосредственно в карточке товара. Ссылки без подтверждённой цены или единицы отображаются в разделе «На проверку»: можно открыть источник и внести проверенное КП. Во внешние сервисы передаются публичная поисковая фраза и, при оценке ИИ, распознанные технические параметры и открытые данные продавца.

Глубокий поиск расширяет запрос синонимами и ключевыми параметрами. Если Exa недоступен, проверяются каталоги поставщиков. Цель — пять сопоставимых цен от разных продавцов и вариация до 20%. Если цель не достигнута, сервис показывает фактический результат.

## Поток данных

1. Браузер извлекает позиции и требования из таблиц DOCX. Документ не отправляется на сервер. Пользователь может исправить позиции и проверяет публичные запросы для исходного товара и аналогов.
2. Браузер отправляет серверу запрос и описание отдельной позиции, нужное для сравнения. Внешние поисковые сервисы получают короткие публичные запросы. Сервер начинает с ЕИС, затем проверяет обязательные площадки и каталоги. Поиск аналогов дополняет выборку отдельными запросами.
3. Адаптеры сохраняют ссылку, поставщика, цену, единицу, доступные характеристики и время получения. Правила в `public/analysis.js` сравнивают характеристики, приводят известные фасовки к нужной единице и объясняют решения. Кандидаты в аналоги требуют проверки в строгом режиме. Для 3D-принтера другой модели требуется ручное подтверждение также в режиме «Лайт».
4. В строгом режиме используется по одной цене на продавца. При четырёх и более ценах исключаются значения ниже 65% или выше 145% медианы. Рекомендуемая цена требует от трёх поставщиков и вариации до 33%. Лайт показывает ориентир. Сводный итог становится рекомендуемой НМЦД только при надёжном расчёте по всем позициям.
5. Отчёт содержит расчёт по каждой позиции, ссылки, исходные и нормализованные цены, характеристики, причины решений. Доступны HTML, XLSX и печать в PDF.

Адаптеры находятся в `sources.mjs`, чтение карточек в `product-cards.mjs`, импорт DOCX в `public/specification.js`. Доступ и цены зависят от региона и наличия. Доставку, НДС и минимальную партию следует сверять по данным поставщика.

## Сценарии

1. **ТЗ на поставку бумаги.** Загрузите [учебное ТЗ на бумагу](examples/paper.docx) или DOCX организаторов. Проверьте три позиции: 2 500 пачек офисной А4, 25 пачек офисной А3 и 50 пачек офсетной А4. Запустите поиск по всем позициям и откройте обоснование. Отчёт показывает каждую позицию и отмечает отсутствие цены или недостаток сопоставимых источников.
2. **ТЗ на поставку 3D-принтера.** Загрузите [учебное ТЗ на 3D-принтер](examples/printer.docx) или DOCX организаторов. Проверьте запрос для CreatBot D600 Pro и запрос аналогов по технологии FDM и объёму печати. В результатах откройте «Аналоги», затем карточку предложения с подтверждёнными, отличающимися и отсутствующими характеристиками.
3. **Стаканы.** Нажмите «Стаканы» для демонстрации без сетевого поиска. В строгом режиме две подтверждённые цены и одна цена на проверку дают предварительную оценку 4 000 ₽ за 500 шт. Стаканы меньшего объёма исключены.

## Источники ТЗ

- [Условие и список источников организаторов](https://drive.google.com/drive/folders/1vyRROCVs0rZ8iqmjam8Q1vaHPcnJcMwB)
- [Страница хакатона](https://hack80.phystech-union.org/)

Поиск начинается с реестра контрактов ЕИС и затем проходит по федеральным площадкам, агрегаторам и каталогам. Маркетплейсы запускаются при подтверждённой пустой выдаче ЕИС. Если площадка блокирует автоматическое чтение или отдаёт только ссылки, статус источника и ссылка на него видны в результатах. Суммы контрактов и начальные цены процедур не используются как цены за единицу.

Для подключения Timeweb задайте `PRICE_LAB_AGENT_ID` и `PRICE_LAB_AGENT_TOKEN`. Приложение не ограничивает общее число вызовов и не устанавливает дату их окончания. Тарификация и ограничения аккаунта действуют на стороне Timeweb.

Для демонстрации жюри используйте [сверку с критериями](CASE-CHECK.md).

### Дополнительная проверка в глубоком поиске

Сервис повторно открывает карточки с пропусками в полях, читает наложенные на страницу технические таблицы и структурированные характеристики. Для поддерживаемых ревизий CreatBot подтягивает паспорт производителя по точной модели. В карточке каждого найденного параметра есть ссылка на источник. Товар другой ревизии требует подтверждения как аналог.

Для независимой перепроверки задайте `PRICE_LAB_VERIFIER_ID` и `PRICE_LAB_VERIFIER_TOKEN` второго агента Timeweb. Он получает только публичный запрос, распознанные требования и выдержки из открытых карточек. Вывод применяется, когда цитата есть в источнике и из неё можно извлечь значение. Если модель недоступна, действуют локальные правила.

Для полной цены укажите в проверенном КП регион, стоимость доставки всей позиции и режим НДС. Цена с доставкой выводится для всей используемой выборки при одинаковом регионе, количестве и применении НДС. Объявленный тариф из карточки продавца показывается в справочном виде до подтверждения стоимости всего заказа.

Раздел «Статистика глубокого поиска» показывает количество подтверждённых цен до и после расширения, карточек на проверке, число повторных чтений и длительность. Команда `node --test quality.test.mjs` проверяет размеченные примеры для бумаги, принтеров, цитокинов и услуг. Это контрольные примеры, для оценки готовности дополнительно проверяйте живые источники.
